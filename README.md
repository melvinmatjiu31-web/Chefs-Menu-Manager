 Chef's Menu Manager

 Project Description

Chef's Menu Manager is a React Native mobile application designed to help a restaurant chef manage menu items digitally.

Features

- Add menu items
- Enter dish name
- Enter dish description
- Select a course
- Enter the price
- View all added menu items
- Validation for required fields
- Success confirmation after adding an item
- Message displayed when there are no menu items

 Courses

- Starter
- Main Course
- Dessert

 Technology Used

- React Native
- Expo
- JavaScript
